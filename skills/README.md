# Skills — the production playbooks

The video-making skills and pipeline docs live here, at the repo root, separate
from the assets they operate on. These are the canonical packages: full working
skills (SKILL.md + skill.yaml), re-synced from Muse's working copies whenever
the production rules change.

| Path | What it is |
|---|---|
| `PRODUCTION.md` | The end-to-end episode pipeline — the operating manual. Start here. |
| `ASSET-GENERATION.md` | How every asset is made: cast design flow, STYLE LOCK, rig sheets, voice casting, music pool, repo conventions. |
| `local-fantasy-recap-video-qc/` | The recap release gates. This is the law; PRODUCTION.md is the summary. |
| `local-goat-hoopers-hype-video/` | The beat-synced hype-video playbook (preseason/specials, clip sourcing, final-file verification). |

The assets these skills operate on live in [`../goat-hoopers/`](../goat-hoopers/)
(the GOAT Hoopers library, scenes, and voice casting) and
[`../general/`](../general/) (shared identity refs + the music pool).
